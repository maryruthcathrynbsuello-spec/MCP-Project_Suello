## M4: Protocol
- Handoff protocol: init_handoff and append_handoff manage handoff/PROJECT_STATE.md, PLAN_LOG.md, CHECKPOINTS.md, DECISIONS.md (docs/m4-handoff.png)
- PLAN_LOG, CHECKPOINTS, DECISIONS are append-only: write_file, str_replace and delete_file are blocked on them; PROJECT_STATE.md is edited with str_replace
- Git-lite: git_status, git_commit, git_log run git via execFile (no shell) inside workspace/.git; commits are authored "MCP Agent", with hooks skipped (docs/m4-git.png)
- Sandbox hardening: .git folders are off limits to file tools (git hooks could run code); blocked Windows aliases (GIT~1, trailing dot, ":" streams)
- Guards: 1,000,000-character write limit, docx limits, 2,000-character handoff entries, 200 KB log cap, handoff folder and .trash cannot be deleted (docs/m4-guards.png)
- Server instructions give every new session the protocol (read state, plan first, search before reading, checkpoint and commit at the end)
- 13 tools in total. Tests: sandbox + guards, all passing (docs/m4-tests.png)
- Deployment note: pm2 runs dist/, so changes need npm run build and pm2 restart
